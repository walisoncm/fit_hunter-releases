# ✨ Fit Hunter v1.5.2 — Nutrition Card Fix

## 🛠️ Improvements & Fixes

- **Nutrition Card Always Visible**: The "Metabolic Fuel" card on the Status screen is now always shown. When no meals have been logged yet, it explains that meals recorded in apps connected to Health Connect will appear there.
- **Fewer Health Permissions**: Fit Hunter no longer asks for permission to write nutrition data to Health Connect — it only reads the meals you log in other apps.
